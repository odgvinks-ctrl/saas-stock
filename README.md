# Flow stock 
## Description 
Flow stock est un logiciel qui permet aux boutiques, magasins et commerçants de gérer leurs stocks, suivre les ventes, d'avoir des alertes sur les ruptures de stock et de recevoir des paiements mobiles.
## Fonctionnalités 
- Gérer les stocks
- Suivre les ventes
- Recevoir des alertes des ruptures de stock
- Recevoir les paiements mobiles
## Technologies utilisées 
- Next.js
- Node.js
- Github
## Prérequis 
Aucune extension n'est nécessaire pour le bon fonctionnement du logiciel.
